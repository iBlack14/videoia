# Navegación realista con mascota

Se encontraron los originales de OdiseaCloud en la carpeta local `odisea web nueva/assets/images` y se contrastaron con https://odiseacloud.com/.

Se usaron capturas reales del sitio, una barra de navegador recreada y un cursor animado. Acciones: escribir URL, mostrar carga, abrir información del sitio, seleccionar el dominio y desplazarse entre portada y servicios. El dominio `.invalid` se identifica como ejemplo ficticio.

Mascota original en dos poses: guía y saludo. Animación 2D mediante posición, giro y mezcla de poses; no es una animación 3D articulada ni tiene sincronización de labios.

Revisados los fotogramas a 3, 10, 17, 23 y 25.75 segundos. La advertencia automática de pausa visual no considera el contenido de las imágenes de la web y la mascota; las pausas del panel permiten leerlo durante la narración.

Validación: `ok: true`, sin errores ni advertencias de composición o audio. Dos avisos de pausa visual se aceptaron por las pausas de lectura y el movimiento en capturas/mascota.

Exportación: MP4 de 26.000 segundos, 1080 × 1920, H.264 y audio AAC. Archivo de 3.736.521 bytes. Se extrajo un fotograma del MP4 a los 10 segundos para inspección final. No se publicó en redes.
